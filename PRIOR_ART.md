# Prior-art boundary (working document)

This is a development checklist, not a completed literature or patent review.

Before any public novelty claim, compare AgentBetta against at least:

- earlier academic/software uses of nano-agent terminology;
- hbbio/nanoagent;
- micro-agent and atomic-agent frameworks;
- AOrchestra;
- CodeDelegator;
- AgentSpawn;
- AgentFactory;
- Agent Contracts;
- Efficient Agents;
- task-scoped authorization / least-privilege systems;
- adaptive context, tool and model routing systems;
- relevant patents and newly published work.

Do **not** claim novelty for generic lightweight agents, task-specific subagents, dynamic model selection, tool selection, context curation, ephemeral workers, ordinary least privilege, resource-bounded contracts, or generic Pareto optimization.

The intended differentiator to test is the integrated closed loop:

1. task-conditioned configuration;
2. verified outcome feedback;
3. failure-driven dimension-selective expansion;
4. post-success counterfactual contraction; and
5. learning from expansion and contraction evidence.
